작성: 2026-07-14 · 상태: **설계 확정 — 개발 대기** · 구현 담당에게 그대로 전달되는 스펙.

> **한 줄 컨셉:** 백지가 무서운 수험생을 위한, 뼈대에서 시작해 말로 가르치며 완성하는 인출 훈련 파트너

## 1. 문제 정의

백지인출·가르쳐보기를 하고 싶지만 장벽이 있음. 장벽 우선순위 (사용자 본인 기준):

1. **시작 장벽** — "뭐부터 인출하지?" 범위 선택과 백지의 부담
2. **감정 장벽** — 생각보다 안 나오면 자기비판 스위치 (§0-2 기질 규칙 대응 필요)
3. **기록 장벽** — 약한 지점의 누적 추적 부재
4. **검증 장벽** — 채점은 오히려 후순위

시작 장벽 세부 (우선순위): **B 백지의 부담 > C 완벽주의 > A 범위 선택**
→ 결론: 채점 도구가 아니라 **"인출을 시작하게 만드는 도구"**. 완전 백지가 아닌 **키워드 뼈대**에서 출발 (cued recall → free recall 점진 이행).

## 2. 핵심 설계 결정

| 항목 | 결정 | 근거 |
|------|------|------|
| 인출 방식 v1 | **음성 설명 (가르쳐보기)** | 설명형 학습이 최강 학습 방식, 기록은 자동 텍스트화 |
| AI 역할 | **질문하는 학생** (파인만 모드) | 막히는 지점 = 안다고 착각한 지점. NS 95에 긴장감 있는 대화가 몰입 장치 |
| 막혔을 때 | **힌트 계단** (단계별 힌트) | "막힘 = 실패"가 아니라 "힌트 게임"으로 리프레임, 끝까지 스스로 인출 |
| 기록 언어 | "약점" 대신 **"힌트 사용 횟수"** | 팩트 기반 기록, 0계단 도달이 성장 지표 (자기비판 대응) |
| 기록 저장 | v1: **원탭 옵시디언 저장(URI)** → v2: git 경유 완전 자동 | §8 결정 로그 D2 |
| 뼈대 콘텐츠 | **교재 → AI 뼈대 자동 생성** (v1은 로컬 임포트 스크립트) | 기존 RAG 청킹 파이프라인 재사용. 웹 업로드 개방은 Phase 2 |
| 오늘의 범위 | **자동 결정 (선택지 제시 금지)** | PHASE1_SPEC §0-2 규칙 4. 기존 `/review/today` 큐 로직 재사용 |

### 기질 하드 규칙 적용 (PHASE1_SPEC §0-2 준수 — 전 화면 공통)
- 힌트 데이터는 기록하되, 화면 노출은 **오르는 지표만**: "0계단 도달 개념 N개(누적)", "인출 세션 M회(누적)".
- **금지**: "약한 개념 TOP 5", 힌트 많이 쓴 순 정렬, 세션별 점수 비교, 스트릭. 추후 대시보드를 만들 때도 이 조항이 우선한다.
- 세션 종료 화면은 성취만: "오늘 2개념 인출 완료 · 그중 1개는 힌트 없이".

### 저작권 설계 원칙
- 업로드 원문은 처리 후 최소 보관, 뼈대(파생물)만 유저 개인 공간에 저장.
- 유저 간 원문 공유 금지 (약관 작성 시 재검토). Phase 2 스토리지 정책으로 구현.

## 3. v1 사용자 플로우

1. AI가 오늘의 인출 범위 **자동 제시** (SR 큐 기반, 선택지 없음)
2. 키워드 뼈대 제공
3. 음성으로 설명 시작 (1~2주차는 타이핑)
4. AI 학생이 질문하며 파고듦 (파인만 모드)
5. 막히면 힌트 계단 (1계단씩)
6. 세션 전체 텍스트 + 힌트 데이터 저장 → 옵시디언 원탭 내보내기

## 4. 아키텍처 (점검 확정)

**teacherExam에 얹는다. 별도 앱 금지.** 이유: Supabase·RAG·배포 파이프라인 공유, 운영 서버 1대(1GB) 유지.

### 4-1. 재사용 (검증 완료 — 전부 실재)
| 필요 기능 | 재사용 대상 |
|---|---|
| 교재 청킹·임베딩 | `backend/ingestion.py` (`chunk_pages`, `embed_chunks`(Voyage), pgvector) |
| 검색 | `search_chunks()` / `match_chunks_pages()` |
| AI 호출 패턴 | `question_gen.py`의 Anthropic 연동 |
| 오늘의 범위 선정 | `/review/today` 큐 로직 (`main.py`) |
| 화면 | Next.js `frontend/app/` 에 `/recall` 페이지 추가 |

### 4-2. 신규
- **테이블** (Supabase, 기존 스키마에 추가):
  - `recall_skeletons(id, concept_id fk, keywords jsonb, source_chunk_ids uuid[], created_at)` — 개념당 뼈대 1개
  - `recall_sessions(id, concept_id, started_at, ended_at, transcript jsonb, hint_count int, reached_zero boolean, mode text('text'|'voice'))`
- **API** (nginx가 `/api` prefix를 벗기므로 라우트는 prefix 없이):
  - `GET /recall/today` — 오늘 인출 개념 + 뼈대 (없으면 즉석 생성)
  - `POST /recall/session` / `POST /recall/session/{id}/turn` (파인만 대화 1턴: 유저 발화 → AI 학생 질문 or 힌트) / `PATCH /recall/session/{id}/complete`
- **힌트 계단**: v1은 프롬프트 레벨 구현 — 시스템 프롬프트에 "힌트는 요청 시에만, 1회 1계단(범주→첫 글자→핵심어 절반)" 명시. `hint_count`는 서버가 카운트.
- **STT**: 브라우저 Web Speech API (`ko-KR`). **HTTPS 필수** — §8 D1에 따라 스프린트 전 선행 완료됨을 전제.
- **뼈대 생성 스크립트**: `backend/build_skeletons.py` (로컬 실행, `import_notes.py` 패턴) — 개념별 상위 chunks에서 키워드 5~9개 LLM 추출.

### 4-3. v1의 의도적 한계 (Phase 2 과제 — 지금 구현하지 말 것)
- 웹 교재 업로드 개방 (서버 1GB 파싱 부담 → v1은 로컬 임포트)
- 사용자 인증·RLS·사용량 제한 (현재 단일 사용자 + Basic Auth 전제. **본인용 v1과 상용 Phase 2 사이에 아키텍처 단절이 있음을 인지할 것**)
- 옵시디언 완전 자동 저장 (§8 D2)
- 대시보드 (frontmatter가 파싱 재료)

## 5. 주말 스프린트 플랜 (매주 "그날 밤부터 쓸 수 있는 상태"로 종료)

- **선행 (스프린트 전, 반나절): HTTPS 전환** — `docs/HTTPS_MIGRATION.md` 절차대로. 음성 모드(마이크)의 하드 전제조건.
- **1주차: 텍스트 인출 MVP** — 뼈대 생성 스크립트 → `/recall` 페이지에서 타이핑 인출 → AI 피드백
- **2주차: 힌트 계단 + 옵시디언 원탭 저장** — 계단식 힌트, frontmatter 박힌 마크다운을 `obsidian://new` URI로 내보내기
- **3주차: 음성 파인만 모드** — Web Speech API STT, AI 학생 질문 모드 (HTTPS 위에서)
- **4주차: 다듬기 + 실사용 전환** — 이후 개발 중단, 11월까지 사용만. 사용 중 불만 = v2 백로그

옵시디언 frontmatter 스키마 (고정 — 대시보드 파싱 대비):
```yaml
---
주제: <개념명>
힌트횟수: <int>
날짜: YYYY-MM-DD
모드: text|voice
---
```

## 6. 수익화 로드맵 (시험 이후)

**타겟:** 수험생 전반 (공무원, 자격증, CPA 등) — 임용에서 시작해 확장

**모델: 프리미엄 프리 + 월 구독**
- 무료: 텍스트 인출 (월 횟수 제한) — LLM 비용 낮음, 마케팅 퍼널
- 유료: 음성 파인만 모드 — 월 9,900~14,900원 선 (출시 전 원가 재계산), 페어유즈 상한 필수
- 시즌 패스("D-100 패스")는 Phase 3에서 객단가 무기로 추가

**Phases:**
- **Phase 1 (11월~):** 본인 데이터로 검증 완료 → 소발자 "이 도구로 임용 준비한 썰" 콘텐츠화
- **Phase 2:** 임용 수험생 소수 베타 (채널 구독자 = 베타테스터 풀) + 대시보드 구현 + **인증/RLS/사용량 제한/웹 업로드** (§4-3 부채 상환 시점)
- **Phase 3:** 수험생 전반 확장, 구독 오픈, 시즌 패스 추가

**획득 퍼널:** 소발자 영상 → 무료 텍스트 인출 체험 → 음성 모드 결제

## 7. 기술 메모

- 전공 RAG와 파이프라인 공유 구조 (청킹·Voyage 임베딩·pgvector 동일)
- STT: v1은 브라우저 Web Speech API로 타협. 품질 불만 시 v2에서 Whisper 계열 검토
- 파인만 대화는 세션당 다(多)턴 LLM 호출 — 본인 사용은 비용 무시 가능, Phase 2에서 상한 설계
